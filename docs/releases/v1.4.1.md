# Idryx 1.4.1

The `idryx` binaries and the image, `ghcr.io/taipanbox/idryx`, are built on Go 1.27.4, which fixes GO-2026-6859 in `net/http`. The 1.4.0 release was built on Go 1.27.3. No detection, flag, exit status or file format moves.

## Changed since 1.4.0

- #125, `build: Go 1.27.4 for GO-2026-6859`. The `toolchain` line in `go.mod`, the Go version of CI and of the release workflow, and the Dockerfile's Go version move to 1.27.4.
- #124, the README is positioned for the enterprise reader; documentation only.
- #122, the gates no longer end a pipe in a `grep` that exits early (invariant 20).
- #121, the README's stack diagram shows the broker before scopyx and `slo_burn` into Wardryx.
- #123, the actions in the workflows move to newer pinned commits.

## Upgrade

Pull `ghcr.io/taipanbox/idryx:v1.4.1` in place of `v1.4.0`, or download the binary for your platform from this release. No setting, stored state or wire format changes, so there is nothing to migrate. To roll back, run 1.4.0 again.
