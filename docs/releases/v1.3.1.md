# Idryx 1.3.1

A patch release on the 1.3 surface. The binaries and the `idryx` image, `ghcr.io/taipanbox/idryx`, are built with Go 1.27.3, which fixes GO-2026-6809 in `crypto/x509`. Version 1.3.0 was built with Go 1.27.2. Nothing is read, emitted, refused or stored differently, and no frozen name moved: `scripts/compat-surface.sh` holds that.

## Upgrade

Nothing breaks, and an existing run needs no edit. Replace the 1.3.0 binary or image with this one.

## What changed since 1.3.0

- **Go 1.27.3 (#115).** The `go.mod` toolchain, the CI and release `go-version`, and the Dockerfile Go version move from 1.27.2 to 1.27.3, so `govulncheck` is clean again and the published binaries and image carry the fixed standard library. No source file of idryx changes.

No other commit lies between the 1.3.0 tag and this release.

## Evidence and limit

- 403 test functions (README badge 403), unchanged from 1.3.0, since no test was added or removed.
- The Go version of the shipped binary is read with `go version` from the published image after the tag is pushed.

## Not proven

- Whether GO-2026-6809 was reachable from idryx's own code under Go 1.27.2 was not measured. The bump removes the question rather than answering it.
- The release and image jobs run only on the tag push.
